# Practice datasets

This folder contains small, synthetic datasets created for demonstrations. They are not official university datasets and should not be presented as real-world measurements.

## Files
- `toy_travel.csv`: a tiny travel example with distance, cost, duration, and a made-up service category.

## Safe use
- Inspect units and column meanings before training.
- Keep the target column separate from input features.
- Do not draw scientific or business conclusions from a handful of synthetic rows.
- For reproducibility, record the dataset version and random seed when generating larger examples.
