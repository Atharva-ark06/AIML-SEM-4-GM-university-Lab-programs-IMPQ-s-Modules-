# Contributing

Thanks for helping improve this AIML study repository.

## Good contributions
- Correct an error in an explanation or runnable example.
- Add a small, focused algorithm demonstration with comments.
- Improve setup instructions or the resource catalog.
- Add tests for maintained examples.
- Add a study guide that clearly distinguishes verified course material from general revision notes.

## Before opening a pull request
1. Keep changes focused and use descriptive commit messages.
2. Use Python 3.10+ and avoid machine-specific absolute paths.
3. Add a `main()` guard to runnable scripts.
4. Do not silently change original assignment files; add a corrected or explained version separately when appropriate.
5. Run `python -m pytest` after installing `requirements.txt`.
6. Explain what you changed and how you checked it.

## Data and academic integrity
Do not add personal student data, credentials, tokens, or copyrighted content without redistribution permission. Do not claim synthetic examples are real measurements. Exam-preparation notes are not predictions or guarantees.

## Style
Prefer readable names, short functions, comments that explain why, and explicit random seeds in demonstrations that need reproducibility.
