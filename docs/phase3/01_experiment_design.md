# Experiment design for ML

A good ML experiment starts with a question, not a model leaderboard.

## Checklist
- Define the prediction target and intended use.
- Identify the unit of analysis and data collection process.
- Choose a baseline before tuning complex models.
- Separate training, validation, and final test data.
- Select metrics based on the cost of false positives and false negatives.
- Record dataset version, random seed, parameters, and limitations.

## Report
State the question, data split, baseline, selected model, metric, uncertainty, and known failure modes.
