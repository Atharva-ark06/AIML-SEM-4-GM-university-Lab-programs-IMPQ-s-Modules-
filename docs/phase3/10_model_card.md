# Model card template

Use this template when documenting a trained model.

- **Purpose:** intended task and users.
- **Data:** sources, time period, licensing, and exclusions.
- **Evaluation:** split strategy, metrics, and baseline.
- **Limitations:** known weak areas and unsupported use cases.
- **Risks:** privacy, fairness, security, and misuse concerns.
- **Monitoring:** signals, owners, alert thresholds, and rollback.
- **Version:** code, data, and model identifiers.

Do not present a model as validated for uses that were not evaluated.
