# Phase 2 — applied AI/ML learning track

This phase extends the semester lab collection with small, testable reference implementations and revision notes.

## Learning sequence
1. Data quality and exploratory analysis
2. Preprocessing and leakage prevention
3. Model selection, validation, and metrics
4. Clustering, dimensionality reduction, and interpretation
5. Reproducible experiments and responsible reporting

## Conventions
- Examples use small or synthetic data so they can run locally.
- Each example explains assumptions and expected output shape.
- Install optional dependencies only when an example requires them.
- Treat results as demonstrations, not as evidence about real populations.

Start with the workflow guide, then follow the numbered guides.
