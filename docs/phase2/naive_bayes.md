# Naive Bayes

Naive Bayes applies Bayes' rule with a conditional-independence assumption among features given the class. The assumption is often unrealistic, yet the method can work well for some text and high-dimensional tasks.

Gaussian Naive Bayes suits continuous features under a Gaussian likelihood; Multinomial Naive Bayes is often used for non-negative counts; Bernoulli Naive Bayes models binary features. Choose the variant based on feature representation.
