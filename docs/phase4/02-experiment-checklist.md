# Experiment checklist

- [ ] Write the question and intended use.
- [ ] Record dataset source, version, and permitted use.
- [ ] Identify target, features, units, and row meaning.
- [ ] Remove identifiers that should not be model inputs.
- [ ] Define train/validation/test strategy before tuning.
- [ ] Fit transformations on training data only.
- [ ] Establish a majority or mean baseline.
- [ ] Choose metrics before looking at final test results.
- [ ] Inspect errors across relevant subgroups.
- [ ] Save seed, configuration, package versions, and results.
- [ ] Document known limitations and intended non-uses.
