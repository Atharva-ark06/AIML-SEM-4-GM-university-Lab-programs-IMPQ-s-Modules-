# Phase 4: Learning objectives

This phase focuses on building trustworthy, repeatable machine-learning experiments. By the end, a learner should be able to define a baseline, split data without leakage, compare models, inspect errors, and communicate limitations.

## Workflow
1. State the prediction task and target.
2. Inspect rows, columns, types, missingness, and target balance.
3. Create a reproducible split.
4. Fit preprocessing only on training data.
5. Compare a simple baseline with candidate models.
6. Evaluate using task-appropriate metrics and inspect failure cases.
7. Record limitations and rerun instructions.
