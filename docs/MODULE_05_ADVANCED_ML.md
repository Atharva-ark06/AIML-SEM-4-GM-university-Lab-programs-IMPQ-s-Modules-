# Module 5 — advanced machine-learning topics

## Clustering
Clustering groups examples using a similarity or distance criterion without requiring known class labels. K-means alternates between assigning points to the nearest centroid and updating centroids to the mean of assigned points.

## Bayesian learning
Bayesian methods update beliefs using prior information and observed evidence. Naive Bayes uses Bayes' theorem with a conditional-independence assumption between features given the class. This assumption is often imperfect, but the model can still be useful.

## Artificial neural networks
A neural network combines weighted inputs, biases, activation functions, and layers. Training adjusts parameters to reduce a defined loss, often with gradient-based optimization.

## Model selection and responsible interpretation
- Scale features where the method requires it.
- Fix random seeds for reproducible demonstrations.
- Inspect class balance and missing values.
- Use validation data for tuning.
- Report limitations and avoid overstating small-sample results.
