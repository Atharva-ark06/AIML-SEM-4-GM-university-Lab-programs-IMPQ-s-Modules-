# Assignment and lab-report guide

Use your faculty's required template when one exists. This checklist helps make a submission reproducible and understandable.

## Suggested report structure
1. **Title and objective:** state the problem clearly.
2. **Theory:** define the algorithm and important terms.
3. **Method / algorithm:** ordered steps or pseudocode.
4. **Implementation:** language, packages, inputs, and key functions.
5. **Output:** include genuine output from your own run.
6. **Interpretation:** explain what the output means.
7. **Limitations:** assumptions, edge cases, or small sample size.
8. **Conclusion:** summarize what was learned.
9. **References:** cite course notes and external material used.

## Reproducibility
Record Python and package versions when relevant. Use fixed random seeds for demonstrations. Do not fabricate screenshots, accuracy scores, datasets, or experimental results.

## Code quality
Prefer descriptive variable names, modular functions, input checks, and comments explaining non-obvious decisions. Ensure the submitted code is your own work and follows your institution's rules.
