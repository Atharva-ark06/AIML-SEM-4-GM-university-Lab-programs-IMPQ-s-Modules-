# AIML learning roadmap

A practical order for learning the topics represented in this repository.

1. **Python and data:** lists, dictionaries, functions, NumPy arrays, pandas DataFrames, and plots.
2. **AI problem solving:** state spaces, goal tests, BFS, DFS, heuristic search, and AO* graph structure.
3. **Data preparation:** identify target/features, inspect missing values, encode categories, split data, and scale numerical features.
4. **Supervised learning:** understand KNN, linear regression, decision trees, and Naive Bayes.
5. **Unsupervised learning:** distinguish clustering from classification; study K-means and cluster evaluation.
6. **Evaluation:** choose metrics that fit the task, inspect confusion matrices, and avoid evaluating on training data only.
7. **Explain your work:** describe assumptions, algorithm steps, output meaning, limitations, and possible improvements.

## A repeatable study loop
- Read the concept guide.
- Trace one tiny example by hand.
- Run the related Python file.
- Change one input or parameter.
- Predict the effect before rerunning.
- Explain the result without reading the source.

## Completion checklist
- [ ] I can state the problem and input/output.
- [ ] I can explain the algorithm in ordered steps.
- [ ] I can trace a small example manually.
- [ ] I can interpret the output and metric.
- [ ] I can state at least one limitation.
