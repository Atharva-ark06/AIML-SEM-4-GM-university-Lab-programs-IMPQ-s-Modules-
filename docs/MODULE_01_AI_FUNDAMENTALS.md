# Module 1 — AI fundamentals

## Core idea
Artificial Intelligence (AI) studies computational systems that perform tasks associated with intelligent behaviour, such as reasoning, search, learning, perception, and decision-making.

## Important terms
- **Agent:** an entity that perceives an environment and takes actions.
- **State:** a representation of the situation at a particular point.
- **Initial state:** where problem solving begins.
- **Goal test:** determines whether a target condition is satisfied.
- **State space:** all states reachable or considered by a problem formulation.
- **Search strategy:** a rule for choosing which state to explore next.

## Problem-solving workflow
1. Define the problem and constraints.
2. Represent states and legal actions.
3. Specify the initial state and goal test.
4. Choose a search or learning method.
5. Run the method and inspect the result.
6. Evaluate cost, correctness, and limitations.

## Search vocabulary
A path is a sequence of states connected by actions. Path cost accumulates action costs. A heuristic estimates the remaining cost to a goal; it is an estimate, not necessarily the exact answer.
